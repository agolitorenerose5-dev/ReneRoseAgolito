# 📍 Campus Lost & Found System

A web-based platform for students to report lost items and view found belongings within the campus. Built with **Flask** and **PostgreSQL**.

## 🚀 Features
* **Public Board:** View all active lost reports in real-time.
* **Reporting System:** Easy-to-use form for students to submit item details and locations.
* **Admin Dashboard:** Secure management area to mark items as "Found" or delete old records.
* **Responsive UI:** Built with Bootstrap 5 for mobile and desktop support.

## 🛠️ Tech Stack
* **Backend:** Python (Flask)
* **Database:** PostgreSQL (deployed on Render)
* **Frontend:** HTML5, CSS3 (Bootstrap 5)
* **Server:** Gunicorn

## 📦 Setup Instructions
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`.
3. Set your `DATABASE_URL` environment variable.
4. Run the app: `python app.py`.
